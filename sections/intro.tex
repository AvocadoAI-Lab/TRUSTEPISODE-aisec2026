\section{Introduction}
\label{sec:introduction}

Multi-step attacks rarely produce one conclusive alert. A remote connection, script execution,
file transfer, or administrative action can be benign alone yet material when connected by
time, entity, session, and process relations. Endpoint detection and response (EDR) and network
detection and response (NDR) also fail differently: an event may be absent because no action
was observed, because no detector fired, or because a collector or parser was unavailable.
Treating all three states as zero evidence silently changes both correlation and probability
semantics.

Existing alert correlation and provenance systems reconstruct causal context, but their
candidate boundaries, late-data behavior, and calibration contracts are often not explicit
enough for byte-identical replay~\cite{ning2002attackscenarios,holmes2019,nodlink2024,kairos2024}.
Conversely, an anomaly or severity score is not automatically a probability, and calibration
is meaningful only for the candidate population and pipeline version on which it was
validated~\cite{guo2017calibration,gneiting2007proper}. These gaps are coupled: changing
episode membership changes the scored population, while hiding source failure behind a zero
feature can make an unsupported mapping appear confidently benign.

\trustepisode addresses this problem with a deliberately narrow contract. It transforms only
EDR/NDR observations into deterministic EpisodeRevisions, computes a compact raw logit from
detector deviation and independent corroboration, emits a calibrated probability only under
an exact manifest match, reports evidence sufficiency independently, and assembles one
        canonical terminal assembly outcome per revision. Ground truth is unavailable to every online producer and
is joined only after inference.

\paragraph{Contributions.}
This paper makes four contributions:
\begin{enumerate}[leftmargin=*,itemsep=1pt,topsep=2pt]
  \item a single-owner online object model and deterministic episode state machine with fixed
        guards, total ordering, watermark, and revision policy;
  \item a compact scorer plus manifest-scoped affine calibration that returns canonical null
        outside validated support;
  \item explicit detector-availability and five-axis sufficiency truth tables, together with a
        schema-ready AuditRecord contract with closed types, nullability, and digest sets; and
  \item a CALDERA-based validation protocol on isolated live Linux systems, with fixed scenario
        cards, paired telemetry perturbations, physical outages, sufficiency-transition analysis,
        matching, and run-level statistics.
\end{enumerate}
