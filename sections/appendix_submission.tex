absent but cannot change a required field's meaning.

Identifiers are non-empty UTF-8 strings. Times are UTC RFC~3339 at microsecond precision.
Health is \{\path{healthy}, \path{degraded}, \path{down}, \path{unknown},
\path{not_applicable}\}. Raw pointers contain an immutable object ID, SHA-256 digest, record
locator, and storage-schema version. Canonical JSON uses lexical keys, domain-ordered arrays,
shortest round-trip decimals, and no NaN/infinity; unsupported $P$ is literal \texttt{null}.
The SHA-256 payload excludes host/time/process runtime metadata. Online allowlists reject
labels, scenario/operation/ability IDs, attack windows/markers, and split assignments. Storage
denies \texttt{UPDATE}/\texttt{DELETE}; a correction emits a successor revision and record.

\subsection{Episode Synthesis and Replay}
\label{app:episode-algorithm}

Eligibility uses inclusive $W_{\mathrm{gap}}$ and $W_{\max}$ bounds and requires at least one
process-causal, authenticated-session, endpoint-mapped connection, or specific-entity relation;
hub-only support is forbidden. Candidates use the sole total order
\begin{equation}
(-\rho,-n_R,\Delta_t,t_{\mathrm{start}},\mathrm{episode\_id}),
\end{equation}
with relation precedence process-causal, session, endpoint-mapped, then entity equality. Zero,
one, and multiple candidates respectively start, attach, or merge only when component and
cross-episode guards pass; otherwise the first ordered candidate receives the event. Start IDs
hash policy version, first event ID, and namespace; merge IDs hash \texttt{merge}, sorted parent
IDs, and policy version. Membership order is
$(t^{event},t^{ingest},\mathrm{source\_instance},\mathrm{event\_id})$. Event time controls
relations; ingest time controls the watermark. Accepted late evidence emits $r+1$ and one new
AuditRecord. Replay equality covers IDs, membership, links, lineage, $D,C,z,P,\kappa,U$,
versions, evidence references, and canonical digests.

\subsection{Calibration Manifest and Eligibility}
\label{app:calibration-manifest}

The manifest binds formation/candidate/label policy; feature and detector contracts; CDF,
raw-model, coefficient, train-split, calibration-split, and calibrator digests; exact source
masks and health regimes; schema/parser/pipeline versions; support counts; gate evidence; and
reliability bins. No nearest-mask or nearest-version match is allowed. A group is enabled only
after pre-registered positive, negative, and independent-run minima and held-out run-fold
improvement in both Brier and NLL without direction reversal. Gate failure falls back to
\path{supported_global}; any required contract mismatch yields \path{out_of_support},
canonical-null $P$, and \path{decision_eligible=false}.

\subsection{Laboratory and Offline Labels}
\label{app:lab-label-policy}

Every run manifest freezes run/pair IDs; scenario/workload versions; Caldera commit; target,
collector, and container hashes; topology; EDR/NDR/Health Monitor configuration; parser/schema
versions; clock source/skew; seed; harmless marker; cleanup; and incidents. M1--M7 run alone and
with B1--B8; each card fixes repetition before locked collection. Collection failure remains in
R1/failure logs but leaves primary metrics; action failure with healthy collectors enters only
the sensitivity cohort; cleanup failure blocks reuse of that image. Ground truth is stored
under a separate role and joins only after AuditRecord insertion by run ID, harmless marker,
entity namespace, time interval, and label-policy digest. The companion reproducibility
appendix retains each card's ordered actions, expected observations, and cleanup procedure.

Identity is excluded from NormalizedEvent, Episode Synthesis, candidate IDs/membership,
$D,C,z$, every calibrator manifest, and all primary RQs. A timestamp/provenance/health/support
pilot gate may permit only an offline, separately labeled exploratory annotation after primary
inference; it cannot alter the EDR/NDR candidate universe or $K=2$ contract.

\subsection{Experimental and Result Contract}
\label{app:experimental-contract}
\label{app:result-shells}

A predicted stabilized revision is match-eligible only inside the registered time/entity scope
and above $\theta_{\mathrm{match}}$. Maximum-weight bipartite assignment maximizes covered
malicious actions; ties use entity overlap, absolute time difference, then lexical IDs. For
malicious-action set $A$ and assigned covered actions $\widehat A$,
\begin{align}
\mathrm{ActionCoverage}&=|A\cap\widehat A|/|A|,\\
\mathrm{Fragmentation}&=|G|^{-1}\!\sum_{g\in G}\max(0,n_g-1).
\end{align}
Over-merge is the fraction of revisions eligible for multiple runs; contamination is the
unrelated-benign event fraction in revisions assigned to malicious runs. For supported records,
\begin{align}
\mathrm{Brier}&=n_{\mathrm{sup}}^{-1}\sum_i(P_i-Y_i)^2,\\
\mathrm{NLL}&=-n_{\mathrm{sup}}^{-1}\sum_i[Y_i\log P_i+(1-Y_i)\log(1-P_i)].
\end{align}
Unsupported records are excluded from both. Reliability uses ten fixed equal-width bins with
counts; supported coverage is $|\mathcal C_{\mathrm{sup}}|/|\mathcal C|$; fixed-budget recall
uses the top $\max(1,\lceil0.05|\mathcal C_{\mathrm{run}}|\rceil)$ revisions per run. Primary
intervals use 2,000 complete-run cluster-bootstrap resamples with seed 20260710; replay/outage
contrasts resample base-run pairs.
